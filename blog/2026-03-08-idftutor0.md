## Log

Learn ESP-IDF, this make us control our esp chip more subtly and flexibly.

```c
#include<esp_log.h>

void main(){
  // Error
  ESP_LOGE("The traffic light","is off");
  // Verbose
  ESP_LOGV("The traffic light","is off");

  // Warning
  // ESP_LOGW("The traffic light","life remains 5%");
  // ESP_LOGD

  // Information
  ESP_LOGI("The traffic light","is off");

  return ;

}

```
