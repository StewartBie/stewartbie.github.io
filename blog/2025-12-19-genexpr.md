## C functions

1. `getopt()`

Prototype:

```C
int getopt(int argc, char * const argv[], const char *optstring)
```

|para|meaning|
|--|--|
|optarg |当前选项的参数|
|optind| 下一个要处理的 argv 下标|
|opterr| 是否打印错误|
|optopt| 出错的选项|

```C
#include <stdio.h>
#include <unistd.h>

int main(int argc, char *argv[])
{
    int opt;

    while ((opt = getopt(argc, argv, "ab:")) != -1) {
        switch (opt) {
        case 'a':
            printf("option a\n");
            break;

        case 'b':
            printf("option b, value = %s\n", optarg);
            break;

        case '?':
            printf("unknown option\n");
            break;
        }
    }

    return 0;
}
```
